# スマホから自宅PCのClaudeを遠隔操作する3つの道筋（クラウドチャット／Dispatch／Remote Control）

「自宅PCでClaudeに長い作業を任せたまま外出した。出先のスマホから続きを指示できないか？」——製造業の現場を回りながら副業でAIコンサルをしていると、この手の"手が離せない時間"がやたら多いです。この記事では、その方法を調べて整理した内容を、理解できた範囲で正直にまとめます。

## そもそも何が課題なのか

現場に出ていると、PCの前に座れる時間が細切れになります。私の場合はこんな状況が日常です。

- 午前中に自宅PCでClaudeに資料のたたき台を作らせ、そのまま工場へ出勤
- 移動中に「あ、あの観点を追加しておきたい」と思いつく
- 帰宅してPCを開くのは21時。思いついたことは半分忘れている

つまり**「思いついた瞬間」と「PCの前にいる瞬間」がズレる**のが本質的な課題です。メモアプリに書き留めても、結局は帰宅後にPCで打ち直す二度手間になります。

ここを埋める手段として、スマホからPC側のClaudeに直接指示を飛ばす方法を調べました。調べてみると、**「どのClaudeを使っているか」によって答えが3つに分かれる**ことがわかりました。ここが最初の理解のポイントです。

## 結論：Claudeの「どこで動いているか」で方法が変わる

ひとことで言うと、こうなります。

| 使っているもの | どこで動いているか | スマホからの続け方 |
| --- | --- | --- |
| claude.ai のチャット | クラウド（Anthropicのサーバー） | 何もしなくてもスマホでそのまま続行できる |
| Claudeデスクトップアプリ | 自宅PCの中 | **Dispatch** で接続 |
| Claude Code（ターミナル） | 自宅PCの中 | **Remote Control**（`/remote-control`）で接続 |

私が最初につまずいたのは、この区別がついていなかったことです。詳しくは後述します。

### 1. claude.ai のチャット — 実は何も要らない

ブラウザで `claude.ai` を開いて使っているチャットは、**会話の実体がAnthropic側のクラウドにあります**。自分のPCは単なる「窓口」で、PCの電源を落としても会話そのものは消えません。

なので、スマホのブラウザやClaudeアプリで同じアカウントにログインすれば、**PCで途中まで進めた会話の続きがそのまま出てきます**。設定も接続も不要です。

- やること：スマホに Claude アプリを入れる（またはブラウザで claude.ai を開く）
- 同じアカウントでログインする
- 会話履歴から該当のスレッドを開いて、続きを打つ

地味ですが、多くの人にとってはこれで課題の8割が片付きます。「遠隔操作」という言葉から何か大掛かりな設定を想像していた私は、ここで拍子抜けしました。

### 2. Claudeデスクトップアプリ — Dispatch で橋をかける

デスクトップアプリは、自宅PCの中で動いています。PCのファイルを読ませたり、ローカルのツールと連携させたりできる反面、**その実体はPCから出られません**。

ここをつなぐのが **Dispatch** です。スマホ側から、自宅PCで動いているデスクトップアプリのセッションに指示を送る仕組み、という理解をしています。

### 3. Claude Code — `/remote-control` でつなぐ

ターミナルで動かす Claude Code も、同じく自宅PCの中にいます。こちらは Claude Code のセッション内で **`/remote-control`** というスラッシュコマンド（`/`で始まる命令）を実行して、スマホ側と紐づける形です。

Claude Code はコードを書かせるだけでなく、ファイル整理や定型作業の自動化にも使えるので、「仕掛けておいた処理の様子を出先で確認して追加指示を出す」という使い方が想像できます。

## つまずいた点と解決

### つまずき1：「全部同じClaudeでしょ」と思っていた

最大の勘違いはこれでした。私はずっと「Claudeという一つのサービス」として捉えていて、ブラウザのチャットもデスクトップアプリもClaude Codeも、裏では同じものが動いていると思っていました。

だから最初、「スマホから遠隔操作」と聞いて、**一つの万能な方法があるはず**と探し続けて迷子になりました。

**解決したきっかけ**は、「その会話の中身はどのコンピュータのメモリに乗っているのか？」という問いを立てたことです。

- claude.ai のチャット → Anthropicのサーバー上 → だから別の端末からでも触れる
- デスクトップアプリ / Claude Code → 自分のPC上 → だから「外から入る仕組み」が別途必要

この一本の軸で整理した瞬間、3つの方法が「なぜ3つあるのか」まで含めてスッと腑に落ちました。ツールの使い方を覚える前に、**「どこで動いているか」を押さえる**。これは他のAIツールを理解するときにも効く視点だと思います。

### つまずき2：遠隔操作＝セキュリティが怖い、で思考停止していた

「外から自宅PCを操作」と聞くと、現場上がりの人間としては反射的に身構えます。ただこれも整理すると、**claude.ai のチャットを続けるだけなら、そもそも自宅PCに入っていません**。クラウド上の会話を別端末から見ているだけです。

自宅PCに触れるのは Dispatch と Remote Control の2つ。この2つだけを「扱いに注意が要るもの」として分けて考えれば、むやみに怖がらずに済みます。

### 正直に書いておくこと

今回は**理解までで、Dispatch と Remote Control はまだ実際に接続していません**。設定手順の細かい落とし穴や、実運用でどれくらい安定するかは試してから改めて書きます。この記事は「全体像の地図ができた」段階の記録です。

## 明日から使えるチェックリスト

まずはコストゼロ・リスクゼロで効果が出る順に並べました。

1. **自分が普段どのClaudeを使っているか確認する**
   - ブラウザで `claude.ai` を開いている → クラウド型
   - アプリのアイコンから起動している → デスクトップアプリ
   - ターミナル（黒い画面）で `claude` と打っている → Claude Code
2. **ブラウザのチャット中心なら、まずスマホにClaudeアプリを入れる**
   - PCと同じアカウントでログイン
   - PCで適当な会話を1つ作り、スマホで開けるか確認する
3. **「外出前に投げておく」習慣を作る**
   - 出かける前に、時間のかかる調べ物や文章のたたき台をClaudeに頼んでおく
   - 移動中にスマホで結果を見て、追加指示を出す
4. **思いついたことを"メモ"ではなく"指示"として書く**
   - ×「あの資料、コスト観点が足りない」
   - ○「さっきの資料に、導入コストと運用コストを分けた章を追加して」
   - そのまま投げれば動くので、帰宅後の打ち直しが消えます
5. **デスクトップアプリ／Claude Code を使っている人は、Dispatch と `/remote-control` の存在だけ頭に入れておく**
   - 「PCの中で動いているものを外から触る手段がある」と知っているだけで、調べ始めが早くなります

## まとめ

- Claudeの遠隔操作は3通り。claude.ai のチャットならスマホで**そのまま続けられる**（設定不要）。
- 自宅PCの中で動くデスクトップアプリは **Dispatch**、Claude Code は **`/remote-control`** でつなぐ。
- 迷ったら「その会話はどのコンピュータの中にあるか」を考える。これが3つを見分ける軸です。
