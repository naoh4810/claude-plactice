# 名刺データをHTML+SVGで自作し、jsPDFで97×61mmの入稿用PDFにしてアクセアに入稿するまで

デザインソフトを持っていない、でも名刺やチラシを自分で作りたい。そんな中小企業の担当者や個人事業主向けに、私が実際にAIコンサル用の名刺をHTML+SVGで作り、jsPDFでPDF化して印刷会社（アクセア）にオンライン入稿するまでの流れを共有します。学習日は2026年6月17日、入稿完了まで到達した時点の記録です。

## なぜIllustratorではなくHTML+SVGだったのか

名刺を作るとき、普通はIllustratorなどのデザインソフトか、印刷会社のWebテンプレートを使います。私が今回あえてHTML+SVGを選んだ理由は3つあります。

- **テキストで管理できる**：デザインがコード（テキスト）なので、肩書きや電話番号を変えたいときは1行書き換えるだけ。バイナリのデザインファイルと違い、差分も追える
- **AIに書かせられる**：レイアウトの指示を自然言語で出し、生成AIにSVG（図形やテキストを座標で記述する画像形式）を書かせて微調整する、というやり方が取れる
- **サブスク費用がゼロ**：ブラウザとテキストエディタだけで完結する

逆に向かないのは、写真を多用した凝ったデザインや、色の厳密な管理が必要な案件です。名刺のように「文字と線と単色の面」でできているものは、SVGと非常に相性が良いと感じました。

## 97×61mmという数字の意味

今回、PDFの書き出しサイズは **97×61mm** にしました。名刺の仕上がりサイズは一般的に91×55mmです。では残りの6mmは何か。**塗り足し（ぬりたし）** です。

印刷は、大きな紙に刷ってから断裁機で切ります。このとき数ミリのズレが必ず出るため、仕上がり線の外側に上下左右3mmずつ、背景の色や柄を余分に伸ばしておく必要があります。91＋3＋3＝97、55＋3＋3＝61。これが97×61mmの正体です。

逆に内側にも注意が必要で、文字やロゴは仕上がり線から**内側に3mm以上**離します。ここを詰めすぎると、断裁のブレで文字が端で切れます。つまり設計時に意識する枠は、

1. 外枠：97×61mm（PDFのサイズ＝塗り足し込み）
2. 仕上がり線：91×55mm（実際に切られる位置）
3. 安全領域：85×49mm（文字を置いていい範囲）

の3重構造になります。SVGを書くときは、この3本のガイド線を薄い色で先に引いておき、最後に消すのが確実です。

## 実際の手順

1. **SVGで97×61mmのキャンバスを定義する**。`viewBox="0 0 97 61"` とし、1単位＝1mmで考えると座標計算が一気に楽になります
2. **ガイド用の矩形を3つ置く**（外枠・仕上がり線・安全領域）。作業中だけ表示し、書き出し前に削除
3. **要素を配置する**。氏名、肩書き、会社名、連絡先、QRコード。AIコンサルという肩書きは初対面で説明が要るので、裏面に「何ができるか」を3行だけ入れました
4. **ブラウザで表示して確認する**。HTMLに埋め込めばリロードだけで即確認でき、この反復の速さがHTML+SVGの最大の利点です
5. **jsPDFでPDFを書き出す**。単位をmm、フォーマットを配列で指定します

```js
const doc = new jsPDF({
  orientation: 'landscape',
  unit: 'mm',
  format: [97, 61]
});
```

6. **書き出したPDFをAcrobat ReaderなどでサイズとPDFのプロパティを確認**。ページサイズが97×61mm（約275×173pt）になっているかを必ず見る
7. **アクセアのオンライン入稿フォームからアップロード**。サイズ・部数・紙・納期を選び、データを添付して送信

## つまずいた点と解決

**1. mmとptの単位のズレで微妙に小さいPDFになる**

jsPDFはデフォルトの単位がmmではない場合があり、指定を省略すると意図しないサイズになります。`unit: 'mm'` を明示し、書き出し後に必ずPDFのプロパティでページサイズを実測するクセをつけて解決しました。印刷物は「だいたい合っている」が通用しない世界です。

**2. 日本語フォントの扱い**

jsPDFが標準で持つフォントに日本語は含まれていません。テキストとしてPDFに流し込もうとすると、文字化けするか空白になります。対処は大きく2つで、①フォントファイルを埋め込む、②文字を図形（パス）として扱うか、SVG全体を高解像度で画像化してからPDFに載せる。名刺のように文字量が少なく、レイアウトの再現性が最優先の用途では、後者のほうが事故が少ないと判断しました。ただし画像化する場合は解像度が命で、実寸で**350dpi相当**になるよう、書き出し時の倍率を上げる必要があります。97mm幅なら約1336px以上が目安です。

**3. ガイド線を消し忘れる**

これは笑い話ですが、確認用に引いた仕上がり線をそのままPDFに含めてしまうと、名刺に薄い枠線が印刷されます。**書き出し用と確認用でHTMLを分ける**か、ガイドをひとつのグループにまとめて `display:none` で一括切り替えできるようにしておくと防げます。

## 明日から使えるチェックリスト

- [ ] 仕上がりサイズに上下左右3mmずつ足したサイズでデータを作ったか
- [ ] 文字・ロゴは仕上がり線から内側3mm以上離れているか
- [ ] 背景の色や画像は、塗り足し領域の端まで伸びているか
- [ ] 書き出したPDFのページサイズを、プロパティで実測して確認したか
- [ ] 日本語が文字化け・欠落していないか（別PCでも開いて確認）
- [ ] 画像化した場合、実寸で350dpi相当の解像度があるか
- [ ] ガイド線・トンボなど作業用の要素を消したか
- [ ] 印刷会社の入稿仕様ページを、送信前にもう一度読み直したか

## この手法が解決する実務課題

名刺は入口にすぎません。同じ作り方で、研修の配布資料、展示会のチラシ、現場の表示ラベル、棚のPOPまで対応できます。製造業の現場では「表示を少し直したいだけなのに、デザインデータが外注先にしかなくて動けない」という場面が本当に多い。データをテキストで自社に持っておくと、この詰まりが消えます。加えて、文言の修正をAIに任せてSVGを書き換えさせる運用にすれば、修正のリードタイムが「依頼して数日」から「その場で数分」に変わります。

名刺の97×61mmという数字の意味（塗り足し3mm）を理解すれば、HTML+SVG+jsPDFで入稿データは自作できます。つまずくのは単位・フォント・ガイド線の消し忘れの3点で、いずれも書き出し後の実測で防げます。今回は入稿完了までの記録なので、実物の仕上がり確認は次回レポートします。
