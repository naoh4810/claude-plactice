# 月額ゼロで作るLINE公式アカウントのCRM｜OSS「LINE Harness」を Claude Code で立ち上げた記録

「LINE公式アカウントで友だち管理をしたいが、月額のCRMツールは高い」——中小事業者や個人店からよく聞く悩みです。今回は、OSS（オープンソース）のLINE向けCRM「LINE Harness」を GitHub から取得し、Cloudflare の無料枠でゼロから立ち上げて、Webhook連携・友だちの自動登録・Claude Code からのAPI操作までを動かした記録をまとめます。美容サロン向けの提案デモとして構築したものです。ランニングコストをかけずに「まず動くもの」を用意したい方向けです。

## そもそも何を作ったのか

やったことは、ざっくり次の3つです。

- OSSのLINE向けCRM「LINE Harness」を GitHub から clone（コードを丸ごと取得）
- Cloudflare の無料枠にデプロイして、サーバー費用ゼロで公開状態にする
- LINE公式アカウントと Webhook でつなぎ、友だち追加を自動でCRMに登録

Webhook とは、「LINEで何かが起きたら、こちらのサーバーに自動で知らせが飛んでくる」仕組みのことです。これにより、ユーザーが友だち追加した瞬間に、その情報をCRM側へ自動で取り込めます。手作業の名簿入力が要らなくなる、という点が肝です。

## なぜ Cloudflare の無料枠なのか

提案デモの段階では「まず動くものを、コストゼロで見せる」ことが最優先でした。有料のサーバーを契約してから作り込むのではなく、無料枠で公開まで持っていくことで、相手（今回は美容サロン）に実物を触ってもらいながら話ができます。

ポイントは、初期費用と月額をゼロに抑えたまま、「友だち追加 → 自動登録」という価値の中心部分を実際に体験してもらえることです。導入判断は、机上の説明よりも「動いている画面」を見せたほうが早い、という実感があります。

## Claude Code を“作業者”として使う

今回のセットアップは、Claude Code を相棒にして進めました。OSSを clone した後の設定変更や、API操作の確認まで、コマンドや手順を対話しながら詰めていける点が大きかったです。

非エンジニアがOSSをゼロから立ち上げる時、いちばん詰まるのは「READMEに書いてある前提（環境変数、鍵の設定、デプロイ手順）を、自分の環境に翻訳する」ところです。ここを Claude Code に手伝ってもらうことで、手が止まる時間を大きく減らせました。

## つまずいた点と解決

OSSのセルフホストで共通してつまずくのが、**「clone してもそのままでは動かない」**という点です。OSSはあくまで“部品一式”であり、動かすには自分の環境に合わせた設定（連携先の鍵やWebhookの宛先URLなど）を埋める必要があります。

今回も、コードを取得しただけでは友だち登録は動きません。解決の勘所は次の順番で切り分けることでした。

1. まず Cloudflare 側にデプロイして「公開URL」を確定させる
2. その公開URLを、LINE側の Webhook 送信先として登録する
3. 実際に友だち追加して、CRMにレコードが増えるかを確認する

「コードを直す」より前に「つなぎ先の設定が正しいか」を先に疑う——これがセルフホストを最短で動かすコツだと、今回あらためて実感しました。
