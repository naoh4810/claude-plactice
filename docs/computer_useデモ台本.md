# Computer Use デモ台本

AIがパソコンを操作するデモ（`demo/computer_use/`）を、交流会や商談で見せるときの流れとトーク例です。

## 見せ方は2通り

| 場面 | 見せ方 | 時間 |
|---|---|---|
| 交流会・名刺交換の直後 | スマホやPCで**4倍速の録画**を見せる | 1〜2分 |
| 商談・オンライン面談 | **ライブで実行**し、AIが動いている間にヒアリングする | 5〜10分 |

ライブ実行中の4〜5分は「待ち時間」ではなく**ヒアリングの時間**として使うのがコツです。

---

## 共通の流れ

1. **つかみ（30秒）**
   「普段、パソコンで“写すだけ”“まとめるだけ”の作業って、週にどれくらいありますか？」
2. **実行ボタンを押す**
   「今からこのAIに、その作業を頼んでみます。私はマウスもキーボードも触りません。」
3. **実行中（AIが動いている間）**
   - 右側の実況（💬）を指さしながら「いま請求書を開いて、金額を読んでいますね」
   - 相手の業務を聞く（下の「ヒアリング質問」）
4. **結果を見せる**
   - 保存された表と、Slackに届いた報告を見せる
   - 「これを毎朝9時に自動で動かすこともできます」
5. **締め（次の約束）**
   「御社の実際の作業で、どれが置き換えられそうか、30分だけ一緒に洗い出しませんか？」

## シナリオ別トーク

### アンケート回答の集計と報告（`form_survey`）

**合う相手：** 福祉・障害者支援、スクール、サロン、クリニックなど、フォームで回答を集めているところ

- 開始前：「フォームの回答を印刷して書き写したり、手で集計したりしていませんか？」
- 実行中：「いま回答の表をそのままコピーしています。人がやると、ここで写し間違いが起きやすいんです。」
- 集計時：「事業所ごとの平均も、関数で自動計算しています。来月は回答を差し替えるだけです。」
- Slack到着時：「困りごとのトップ3まで、AIが自由記述を読んでまとめています。」

**ヒアリング質問**
- アンケートや申込フォームは月に何件くらい来ますか？
- 集計した結果は、誰に、どんな形で報告していますか？
- 紙やFAXで来るものはありますか？（→ 写真から読み取る提案につながる）

### 請求書PDFの台帳転記とインボイスチェック（`invoice_ledger`）

**合う相手：** 税理士・司法書士・会計事務所、経理担当のいる中小企業

- 開始前：「顧問先から届く請求書や領収書の入力、月にどれくらいありますか？」
- 実行中：「PDFを1枚ずつ開いて、発行元・金額・支払期限を読んでいます。小さい字は拡大して確認しています。」
- チェック時：「2枚目は登録番号が書いてないですね。4枚目は、合計金額が計算と合っていません。こういう確認もAIがやります。」
- Slack到着時：「支払期限が近い順に並べて、取引先に確認すべき点まで報告しています。」

**ヒアリング質問**
- 顧問先からの資料は、どんな形で届きますか？（PDF、紙、写真、会計ソフト）
- インボイス制度の確認で、手間がかかっている作業はありますか？
- 会計ソフトへの入力は、誰がどれくらいの時間をかけていますか？

## よくある質問と答え方

| 質問 | 答え方の例 |
|---|---|
| 間違えることはありますか？ | あります。だから最後に表で確認できる形にして、人がチェックする前提で使います。単純な転記ミスは人より少ないことが多いです。 |
| 社内のデータを外に出して大丈夫？ | このデモは架空データです。実運用では、扱うデータの範囲や保存先を最初に決めてから組みます。 |
| 費用はどれくらい？ | AIの利用料は、このデモ1回で1ドル前後です。運用の仕組みづくりはご相談で見積もります。 |
| うちのシステムでも動きますか？ | 画面を操作するので、APIがない古いシステムでも使えることが多いです。一度画面を見せてください。 |

## 事前チェックリスト

- [ ] `.env` に `ANTHROPIC_API_KEY` と（必要なら）デモ用 Slack の `SLACK_WEBHOOK_URL` を記入した
- [ ] 前日に一度通しで実行し、成功した録画を `recordings/` に残した
- [ ] 会場のネット回線が不安なら、録画を見せる前提にしておく
- [ ] 実際のお客さま情報が画面やSlackに出ないことを確認した
