# 案件チェック自動化（クラウドワークス / ランサーズ / ココナラ / ママワークス）

**自動でやること**: Chrome で巡回 → プロフィールと照合して 〇推奨 / △挑戦 / ×見送り を判定 → 台帳（CSV ＋スプレッドシート）に1案件1行で追記（重複なし）→ Slack に通知（〇△があればメンション付きで要点とURL）

**自分でやること**: 通知を見る → 応募したい案件の ID を伝える（「000313 に応募したい」）→ AI が作った応募文を確認・修正 → **自分で送信ボタンを押す**

```
            ┌──────── 自動（1日2〜3回） ────────┐
Chrome巡回 → 新着だけ本文取得 → NG語なら即× → Claude判定(〇△×)
                                                   ↓
                         data/jobs.csv ＋ スプレッドシート（key で重複防止）
                                                   ↓
                         Slack 通知（〇△ があれば @メンション）
            └──────────────────────────────────┘
                                                   ↓ あなた
            「000313 に応募したい」→ job_apply.py → 応募文 → 確認して自分で送信
```

> 巡回は**自分のPC上で**動かします。各サイトはログインやアクセス元の判定があるため、
> GitHub Actions のようなクラウドからでは安定しません。PC が起動している時間に定期実行します。

## ファイル

| ファイル | 役割 |
|---|---|
| `config/profile.yml` | **プロフィールDB**。スキル・実績・単価下限・NGキーワード。判定と応募文の根拠 |
| `config/job_sites.yml` | 巡回先の一覧URL・案件リンクの形・巡回ペース |
| `scripts/job_hunter.py` | 自動実行の本体（巡回→判定→台帳→通知） |
| `scripts/job_apply.py` | ID を指定して応募文を生成／状態を更新 |
| `scripts/job_crawl.py` | Chrome 操作（初回ログイン、リンク確認） |
| `prompts/job_judge.md` / `prompts/proposal.md` | 判定基準と応募文の書き方 |
| `.claude/skills/job-apply/` | Claude Code で「000313 に応募したい」と言うと応募文を作るスキル |
| `data/` | 台帳 `jobs.csv`・案件本文・応募文（ローカル専用、コミットしない） |

台帳の列: `ID / キー / サイト / 状態(未対応・応募文作成済・応募済・見送り) / 判定 / スコア / 案件名 / 発注者 / 報酬 / 締切 / URL / 要点 / 判定理由 / 不足要件 / 発見日時 / 更新日時`

## セットアップ（初回だけ）

### 1. インストール
```bash
pip install -r requirements-jobs.txt
# PC に Google Chrome があればそれを使います。無い場合だけ:
python -m playwright install chromium
```

### 2. プロフィールDBを書く
`config/profile.yml` の【要記入】を埋めます。**ここに書いたことしか応募文に出ません**（盛らない設計）。

### 3. 環境変数（`.env`）
`.env.example` をコピーして記入します。

| 変数 | 必須 | 内容 |
|---|---|---|
| `ANTHROPIC_API_KEY` | ○ | 判定・応募文生成 |
| `SLACK_WEBHOOK_URL` | ○ | Slack の Incoming Webhook（通知先チャンネルで作成） |
| `SLACK_MENTION_USER` | 任意 | 自分のメンバーID（Slack のプロフィール →「︙」→ メンバーIDをコピー） |
| `GOOGLE_SERVICE_ACCOUNT_FILE` / `JOB_SHEET_ID` | 任意 | スプレッドシートにも書く場合。サービスアカウントを作り、そのメールアドレスにシートを「編集者」で共有 |
| `JOB_MODEL` | 任意 | 既定 `claude-opus-5-5` |

### 4. 専用 Chrome でログイン
```bash
python scripts/job_crawl.py login
```
各サイトのログイン画面が開くので、ログインして Enter。以降はこのログイン状態で巡回します（普段の Chrome とは別プロフィール `.chrome-profile/`）。

### 5. 案件リンクの形を確認（各サイト1回）
```bash
python scripts/job_crawl.py links crowdworks
```
一覧ページのリンクが表示され、`config/job_sites.yml` の `link_pattern` に一致したものに ✔ が付きます。
案件詳細のURLに ✔ が付いていなければ `link_pattern` を直します。**ママワークスは未確認のため既定でオフ**です。
サイトのデザイン変更で拾えなくなったときもこの手順で直します。

### 6. 試運転
```bash
set -a; source .env; set +a
python scripts/job_hunter.py --site crowdworks --max 3 --dry-run   # 判定だけ（台帳・Slackに書かない）
python scripts/job_hunter.py --site crowdworks --max 3             # 本番
```

### 7. 定期実行
- **Mac / Linux（cron）**: `crontab -e` に
  `0 8,12,19 * * * cd /path/to/claude-plactice && set -a && . ./.env && set +a && python3 scripts/job_hunter.py >> data/hunter.log 2>&1`
- **Windows**: タスク スケジューラで `python scripts\job_hunter.py` を 8時・12時・19時に実行（「開始」フォルダをリポジトリに設定し、環境変数はユーザー環境変数に登録）

## 応募するとき

Claude Code で:
> 000313 に応募したい

（`job-apply` スキルが動き、応募文と「送信前チェック」を表示します）

ターミナルで直接:
```bash
python scripts/job_apply.py 000313          # 応募文を生成（data/proposals/000313.md、クリップボードにもコピー）
python scripts/job_apply.py 000313 --open   # 生成して案件ページを専用 Chrome で開く → 貼り付けて自分で送信
python scripts/job_apply.py 000313 --sent   # 送信したら「応募済」に
python scripts/job_apply.py 000313 --skip   # やめたら「見送り」に
```

## 注意とルール

- **送信は自動化しません。** 応募文は必ず目を通し、`【要確認】` を埋めてから自分で送信します。
- 各サイトの利用規約を確認し、巡回は低頻度（1日2〜3回・1サイト十数件まで、ページ間3〜6秒待機）に留めます。
- サイト外取引の誘導・初期費用・個人情報の先出しを求める案件は、判定に関係なく応募しないこと。
- 判定の当たり外れは `config/profile.yml`（特に `notes` と `ng_keywords`）と `prompts/job_judge.md` で調整します。
