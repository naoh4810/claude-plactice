# Asobica コーポレートサイト 分解メモ（LP練習用）

> 対象: <https://asobica.co.jp/>（株式会社Asobica コーポレートサイト / トップページ）
> 目的: LP制作練習のために「構成・配色・コピー」を分解して学ぶ
> 調査日: 2026-09-10
> 調査方法: HTML/公開デザインJSON（STUDIO）+ レンダリング済みテキストを取得して分析

---

## 0. 前提・技術スタック（先に把握しておくと読み解きやすい）

- **制作ツール**: [STUDIO](https://studio.design)（ノーコードWebデザインツール / Nuxt製）で構築
- **サイト種別**: プロダクトLPというより **企業ブランディング + 採用導線を兼ねたコーポレートトップ**
- **プロダクト**: `coorum（コーラム）` ＝ 顧客の「本音」を収集・可視化するLTV向上プラットフォーム
- **本文の入り方**: テキストはCMSからランタイム取得されるSPA。`view-source` には本文が出ないので、練習で模写する際は **実際の描画結果**を見ること

## 1. 構成（セクション順・ワイヤーフレーム分解）

トップページは「**ビジョンの宣言 → 世界観コピー → プロダクト → 採用CTA**」というシンプルな縦積み。
機能羅列や料金表を置かず、**思想（なぜやるか）を前面に出す**のが最大の特徴。

| # | セクション | 役割 | 主な中身 |
|---|-----------|------|----------|
| 1 | **ヘッダー（固定）** | ナビ最小化 | ロゴ / `お知らせ News` / `お問い合わせ Contact` の2リンクのみ。グロナビを削ぎ落とす潔さ |
| 2 | **ヒーロー / ビジョン宣言** | 世界観の提示 | 「顧客中心の経営をスタンダードにする。」を核に、課題→提供価値→ビジョンを**長文のステートメント**で語る |
| 3 | **ブランドコピー** | 情緒のピーク | `Color the world with Asobica innovation` を大きく置く（英語の象徴コピー） |
| 4 | **Products（coorum）** | 事業の説明 | プロダクト名 + 一文価値訴求 + 説明文 + `プロダクト紹介` / `一覧をみる` ボタン |
| 5 | **Recruit（採用CTA）** | 人材獲得の着地 | 「世界をアソビカしよう。」+ メンバー写真 → `/recruit` へ。**最終CTAが採用**なのが採用強めのコーポレートらしさ |
| 6 | **フッター（サイトマップ）** | 回遊・信頼 | 下記サブページ群へのリンク集 |

### サイトマップ（フッター / 下層ページ）
会社情報 / 経営理念 / 創業の思い / 事業戦略 / プロダクト / 役員紹介 / 評価・報酬制度 /
福利厚生・働く環境 / 人材育成 / メンバー紹介 / テーマトーク / 採用情報 / プレスキット /
ニュース / お問い合わせ / 各種ポリシー（情報セキュリティ方針・個人情報保護方針・プライバシーポリシー）

> **構成から学べること**: トップは「売り込み」をせず思想を語り、詳細（機能・制度・人）はすべて下層に逃がす「ハブ型」。
> LP練習では逆に1ページ完結が多いが、**"1ページ＝1メッセージ"に絞る勇気**はこのトップが好例。

## 2. 配色（デザインシステムから抽出した実際のカラー変数）

STUDIOのスタイル変数に定義された**正式なパレット**。温かみのあるグレージュ（ベージュ寄りグレー）を基調にした、彩度低めの上品な配色。

| 役割 | 変数名 | HEX | 使いどころ |
|------|--------|-----|-----------|
| 背景ベース | `bg` | `#DFDAD9` | ページ全体の地色。白ではなく**わずかに赤みのあるグレージュ**で柔らかさと高級感 |
| 背景・明 | `bg_50` | `#EFEDEC` | セクション区切りの中間トーン |
| 背景・最明 | `bg_20` | `#F9F8F7` | カード/余白のほぼ白 |
| 文字・主 | `black` | `#222222` | 見出し・本文（真っ黒を避けた濃グレー） |
| 文字・副 | `black_80 / _60` | `#222222` に透明度 `cc / 99` | 補足テキストの濃淡コントロール |
| 白 | `white` | `#FFFFFF` | 反転パーツ・ロゴ周り |
| アクセント赤 | `red` | `#C84E38` | **テラコッタ/朱色**。差し色（リンク・強調・図版） |
| ブランド黄 | `coorum yellow` | `#FABE0A` | プロダクトcoorum用の象徴色。トップでは限定使用 |

**配色の設計意図（読み取り）**
- 白地ではなく **グレージュ地 `#DFDAD9`** にすることで、写真・余白・黒文字すべてが馴染み「静かで上質」な印象に。
- 彩度を抑えた無彩色ベース + **1色の温かい赤（`#C84E38`）**で差し込む、典型的な「ニュートラル＋1アクセント」構成。
- 透明度付き黒（`cc`/`99`）で文字階層を作り、色数を増やさずに情報の強弱を表現。

> **練習での真似ポイント**: 「地色を#fffから少しだけ外す」「黒は#000でなく#222」「差し色は1色・彩度低め」の3点だけでも一気にそれっぽくなる。

## 3. タイポグラフィ

| 用途 | フォント | 備考 |
|------|---------|------|
| 日本語・主 | **石井ゴシック M / B / R**（TypeSquare / モリサワ系の有料Webフォント） | ウエイトを M(中)・B(太)・R(細) で使い分け。既製感を消す要 |
| 欧文・象徴 | `Bebas Neue` + `Montserrat`、`Inter / Inter Tight` | "Color the world" 等の英字大見出しに強い存在感 |
| 補助 | `Zen Kaku Gothic Antique`, `Noto Sans JP`, `Lato`, `Helvetica Neue` | フォールバック/部分利用 |

**読み取り**
- 日本語に**有料の石井ゴシック**を採用している点が最大の差別化。Noto/ゴシックMB101で代替すると雰囲気は出るが、ブランドは「本文フォント」で語っている。
- 欧文は`Bebas Neue`系のコンデンス体で、余白の効いたレイアウトに縦に締まったタイトルを置いて緊張感を作る。

> **練習での真似ポイント**: 日本語フォントは`Zen Kaku Gothic Antique`や`Noto Sans JP`（無料）で近づけられる。英字見出しだけ`Bebas Neue`にすると一気に"作り込み感"が出る。

## 4. コピー分解

### ① ヒーロー / ビジョン（思想を語る長文型）
> **「顧客中心の経営をスタンダードにする。」** — これが私たちのビジョンです。
>
> 今、日本のGDPを支える数多くのメーカー・小売のオフライン事業者は、なぜ買ったのかという顧客の感情や文脈が見えない、ブラックボックスの中での経営という課題を抱えています。
> 私たちは、人々の「本音」を届けることで、企業と顧客の関係性を「一方通行の消費」から、共にブランドを創り上げる「共創」へと変えていくハブとなります。
> 何百何千もの企業に意思決定の基盤となる幹のデータを届け、何千何万もの生活者に、より豊かなブランド体験を届ける。
> 顧客中心の経営を、誰もが実行できるスタンダードな仕組みへ。

- **型**: 「ビジョン一文 → 課題（Why now）→ 提供価値 → 未来像」の **PAS/ストーリー型**。
- **効かせている言葉**: `本音` `ブラックボックス` `一方通行の消費 → 共創` など、**対比（Before→After）と比喩**で難しい事業を直感的に。
- 数字のレトリック（`何百何千` `何千何万`）でスケール感を演出。

### ② ブランドコピー（象徴）
> **Color the world with Asobica innovation**

- 社名の`asobi（遊び）`と「世界を彩る」ミッションを英語1行に凝縮した**タグライン**。意味伝達よりムード担当。

### ③ プロダクト（coorum）
> **coorum** —「一方通行の消費」から「共創」へ
> 企業は、POSデータで結果は分かっても、なぜ買ったのかの感情や文脈が見えないという課題を抱えています。coorum（コーラム）は顧客の「本音」をユニークな手法で収集・可視化し、企業のあらゆる部門が顧客の声を起点に意思決定できる状態を実現することで、企業と顧客の関係性を双方向の共創へと変革します。
> CTA: `プロダクト紹介` / `一覧をみる`

- ヒーローと**同じ語彙（本音・共創・一方通行）を反復**し、思想とプロダクトを地続きにしている。

### ④ 採用CTA（着地）
> **世界をアソビカしよう。** AI時代の先の未来を、心豊かに彩るために。共に世界を熱狂化する仲間を募集しています。
> CTA: `/recruit`（メンバー写真を添えて）

- 社名を**動詞化（「アソビカしよう」）**した遊び心。最終CTAを販売でなく**採用**に置く設計。

### コピーの共通テクニック（練習メモ）
1. **対比フレーズ**を軸にする（一方通行 ⇄ 共創 / ブラックボックス ⇄ 可視化）
2. **独自の言葉**を作って反復（本音・共創・アソビカ）→ 記憶に残る
3. 機能の前に**課題と世界観**を語る（スペック訴求ではなく意味訴求）
4. CTAは短い体言/呼びかけ（`一覧をみる` `世界をアソビカしよう。`）
