## 学び→記事の運用ルール（おすすめ）
1. 学んだ日、Notionの学習ログに **「つまずき」と「解決」** を1〜2行必ず書く（記事の核になる）
2. `実践度` は正直に付ける（「理解のみ」より「手を動かした/応用できた」がそのまま良記事になる）
3. 生成された下書き（`articles/`）は必ず自分で事実確認してから公開する
4. 週1で `articles/` を見返し、良かった切り口を `prompts/system_prompt.md` に反映する
