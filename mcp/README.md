# MCP デモ集

営業シート（交流会・マッチングアプリで出会った人のログ）から見えた悩みをもとに、
「自分の営業で使う MCP」と「お客さんに見せるデモ MCP」を1本ずつ作っていくディレクトリです。

各サーバーはサブディレクトリごとに独立しています（`requirements.txt` と `README.md` 付き）。
起動はファイルのパスを指定して行います（例: `python mcp/sales_sheet/server.py`）。

> サンプルデータには架空の人物だけを入れてください。実在のお客さまの名前・連絡先はコミットしない。

## ロードマップ
