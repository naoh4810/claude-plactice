# 士業の期限・書類MCP（tax-office）

顧問先ごとの申告・届出の**期限を自動で出し**、期限ごとの**必要書類の回収状況**を追い、揃っていない顧問先への**催促の下書き**まで Claude に任せられるようにする MCP サーバーです。
「顧問先から資料が揃わず、毎回催促に追われる」「期限が顧問先ごとにバラバラで把握しきれない」という税理士・会計事務所、司法書士向けのデモとして作りました。

> **期限は原則的な目安です。** 特例の届出の有無、中間申告の要否、災害による延長などの個別の事情は反映しきれません。税務の判断はしない前提で、最終確認は事務所で行ってください。

## ツール

| ツール | 内容 |
|---|---|
| `office_overview` | 顧問先数、30日以内の期限、期限切れで未完了、書類が揃っていない期限の数 |
| `list_clients` / `add_client` | 顧問先の一覧と登録（条件を入れると期限が自動で出る） |
| `upcoming_deadlines` | 期間内の期限と、期限切れで未完了のもの。書類の揃い具合（例: 4/6）付き |
| `document_status` | 顧問先の書類の束ごとの、受け取り済み・未着 |
| `mark_received` / `mark_done` | 書類の受け取りと、申告・納付・提出の完了を記録 |
| `reminder_candidates` | 期限が近いのに書類が揃っていない顧問先を急ぐ順に。連絡手段と最後に催促した日、最近催促したかの印付き |
| `record_reminder` | 催促したことを記録 |
| `add_task` | 条件からは出ない期限を追加。「出来事の日から何日後」でも指定できる（例: 役員変更登記は変更から2週間） |

プロンプト:

- `weekly_check` : 週の初めに、期限切れ → 今週の期限 → 催促が必要な先、を表にする
- `reminder_drafts` : 催促が必要な先ごとに、連絡手段に合わせた文面（LINE は短く、メールは件名付き、電話は要点メモ）を下書き。送信はしない

## 自動で出す期限

| 条件 | 期限 |
|---|---|
| 法人 | 法人税・地方法人税の確定申告：決算日から2か月以内（申告期限の延長の特例があれば3か月。その場合も**納付は2か月以内**なので、見込み納付を別の期限として出す） |
| 法人・消費税 | 消費税の確定申告：2か月以内（延長の届出があれば3か月） |
| 法人・中間申告 | 法人税の中間申告：事業年度開始から6か月を過ぎてから2か月以内 |
| 個人 | 所得税の確定申告：翌年3/15、消費税（個人）：翌年3/31 |
| 源泉所得税 | 毎月：翌月10日、納期の特例：7/10（1〜6月分）と1/20（7〜12月分） |
| 従業員あり | 法定調書合計表・給与支払報告書：1/31 |
| 償却資産 | 償却資産申告：1/31 |

期限が土日・祝日・年末年始（12/29〜1/3）に当たるときは翌営業日にずらし、「本来は○/○」と添えます。祝日の判定には `holidays` ライブラリを使います（振替休日・国民の休日も含む）。

期限は「書類の束」（決算・確定申告・源泉所得税・年末調整・償却資産・個別）ごとに必要書類を持ちます。法人税と消費税のように同じ束の期限は、1回の依頼で済むようにまとめて扱います。

## デモの流れ（Claude Code で話しかける例）

架空の「サンプル会計事務所」（`sample_office.json`、顧問先6件、今日＝2026-09-30）で試せます。

1. 「今週の期限は？」→ 7月決算のサンプル商事が今日が申告期限で、書類は 4/6。役員変更登記が 10/9
2. 「書類が揃ってない先に催促文を作って」→ 連絡手段（電話・LINE・メール）ごとの下書き。9/18 に催促済みの先はその旨を添える
3. 「サンプルデザインから在庫表が届いた」→ 受け取りを記録し、残りの書類を返す
4. 「サンプル不動産、10/19 に役員が変わったので登記の期限を入れて」→ 2週間後の期限を追加（休日なら翌営業日）

## 動かし方

```bash
pip install -r mcp/tax_office/requirements.txt

# サンプルで試す（変更はメモリ上だけ）
claude mcp add tax-office -- python mcp/tax_office/server.py

# 自分の事務所で使う（顧問先・書類の状況をファイルに保存。リポジトリの外に置く）
claude mcp add tax-office -e OFFICE_DATA_PATH=/path/to/office.json -- python mcp/tax_office/server.py
```

新しく使い始めたときは、使い始めた日より前の期限を「期限切れ」として出しません（過去の分がすべて警告されないように）。

顧問先の名前や書類の状況は守秘義務の対象です。保存ファイルは事務所の中（暗号化されたドライブなど）に置き、共有フォルダやリポジトリには置かないでください。

## テスト

```bash
pip install pytest holidays
python -m pytest mcp/tax_office/test_server.py
```

`mcp/` 配下の各サーバーはモジュール名（`server` など）が同じなので、テストはサーバーごとに分けて実行してください。

## 制限

- 領収書から仕訳 CSV を作る機能は含めていない（仕訳の正しさの確認まで含めると別のデモになるため）
- 住民税の特別徴収、法人住民税・事業税の個別の扱い、予定納税などは未対応
- 催促文の送信はしない（下書きまで。送ったら `record_reminder` で記録する）
