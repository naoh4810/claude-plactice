  1. (−7)−(−2) を計算しなさい。
    正負の数・難易度1・復習
  2. 2x−7x を計算しなさい。
    文字式・難易度1
  3. 3a＋5a を計算しなさい。
    文字式・難易度1
  4. y は x に比例し、x＝2 のとき y＝10 です。y を x の式で表しなさい。
    比例と反比例・難易度1
  5. (−4)×(＋3)−(−6) を計算しなさい。
    正負の数・難易度2・復習
  6. (−2)³ を計算しなさい。
    正負の数・難易度2
  7. 12÷(−4)×(−2)² を計算しなさい。
    正負の数・難易度3
  8. −3²＋(−3)² を計算しなさい。
    正負の数・難易度3

解答・解説

  1. −5
    ひく数の符号を変えて加法にする：(−7)＋(＋2)＝−5。
  2. −5x
    係数どうしを計算：2−7＝−5。
  3. 8a
    文字の部分が同じ項は、係数どうしを足す：3＋5＝8。
  4. y＝5x
    y＝ax に x＝2, y＝10 を代入：10＝2a、a＝5。
  5. −6
    乗法を先に計算：(−4)×(＋3)＝−12。−12−(−6)＝−12＋6＝−6。
  6. −8
    (−2)×(−2)×(−2)＝−8。負の数を奇数回かけると負になる。
  7. −12
    累乗を先に：(−2)²＝4。12÷(−4)＝−3、−3×4＝−12。
  8. 0
    −3²＝−(3×3)＝−9、(−3)²＝(−3)×(−3)＝9。−9＋9＝0。
