# 経費精算マニュアル

サンプル精工株式会社 経理課（架空の会社。デモ用の資料です）

## 1. 基本の流れ

経費は、立て替えた月の翌月5日までに経費精算システムから申請する。所属長の承認後、経理課が確認し、毎月25日の給与と一緒に振り込む。25日が土日祝日の場合は前営業日に振り込む。

## 2. 領収書

領収書は、原本をスマートフォンで撮影して経費精算システムに添付する。撮影後の原本は、申請月の末日まで各自で保管する。

宛名は「サンプル精工株式会社」とする。レシートでも、日付・店名・金額・品目が読めれば領収書の代わりにできる。

領収書をなくしたときは、「支払証明書」の様式に理由を書いて所属長の承認を得る。

## 3. 交通費

### 3.1 電車・バス

公共交通機関の運賃は、経路検索サイトで調べた最も安い経路の金額で申請する。ICカードの利用履歴を添付すれば領収書は不要。

### 3.2 タクシー

タクシーは、次のいずれかに当てはまる場合だけ利用できる。

- 午後10時から午前5時までの移動
- 重い荷物や機材を運ぶ場合
- 公共交通機関がない場所への移動

タクシーを使ったときは、申請に利用した理由を書く。

### 3.3 自家用車

自家用車で業務の移動をしたときは、1kmあたり20円のガソリン代を支給する。事前に所属長の許可を得ること。

## 4. 出張

日帰り出張の日当は1,000円、宿泊を伴う出張の日当は1日2,000円とする。宿泊費は1泊10,000円を上限に実費を支給する。

## 5. 問い合わせ先

経費精算についての問い合わせは、経理課（内線 150）まで。
