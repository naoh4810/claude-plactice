# 就業規則（抜粋）

サンプル精工株式会社（架空の会社。デモ用の資料です）

## 第2章 勤務

### 第10条 勤務時間

所定労働時間は1日8時間とし、始業は午前8時30分、終業は午後5時30分とする。休憩は正午から午後1時までの60分とする。

業務の都合により、所属長は始業・終業の時刻を前後に1時間まで繰り上げ、または繰り下げることができる。

### 第11条 休日

休日は次のとおりとする。

- 土曜日および日曜日
- 国民の祝日
- 年末年始（12月29日から1月3日まで）
- 夏季休暇（8月13日から8月16日まで）

## 第3章 休暇

### 第20条 年次有給休暇

入社日から6か月間継続して勤務し、所定労働日の8割以上出勤した従業員には、10日の年次有給休暇を与える。以後、勤続1年ごとに法定の日数を加算する。

年次有給休暇を取得するときは、原則として取得日の3日前までに勤怠システムから所属長に申請する。急な病気などやむを得ない場合は、当日の始業時刻までに所属長へ電話で連絡し、出勤後速やかに申請する。

年次有給休暇は、半日単位（午前・午後）でも取得できる。半日単位の取得は年10回までとする。

当年度に取得しなかった年次有給休暇は、翌年度に限り繰り越すことができる。

### 第21条 慶弔休暇

従業員が次に該当するときは、慶弔休暇（有給）を与える。

- 本人が結婚するとき：5日
- 子が結婚するとき：2日
- 配偶者が出産するとき：2日
- 配偶者、子、父母が亡くなったとき：5日
- 祖父母、兄弟姉妹が亡くなったとき：2日

慶弔休暇を取得するときは、事前に総務部へ届け出る。

## 第4章 服務

### 第30条 遵守事項

従業員は、会社の許可なく他の会社の役員に就任してはならない。

従業員は、業務上知り得た会社および取引先の情報を、在職中および退職後も第三者に漏らしてはならない。
