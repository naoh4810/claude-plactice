# 情報セキュリティ規程（抜粋）

サンプル精工株式会社（架空の会社。デモ用の資料です）

## 第1章 パソコンと持ち出し

### 第5条 パソコンの社外持ち出し

会社のパソコンを社外へ持ち出すときは、持ち出す日の前日までに情報システム課へ持ち出し申請を行い、承認を得る。

持ち出したパソコンは、電車や車内に置いたまま離れてはならない。紛失・盗難に気づいたときは、直ちに情報システム課（内線 210）へ連絡する。

### 第6条 USBメモリ

USBメモリなどの外部記憶媒体は、情報システム課が貸し出した暗号化機能付きのものに限り使用できる。私物の外部記憶媒体は使用してはならない。

## 第2章 アカウント

### 第10条 パスワード

パスワードは12文字以上とし、英大文字・英小文字・数字・記号のうち3種類以上を含める。他のサービスと同じパスワードを使い回してはならない。

社内システムには多要素認証を設定する。

## 第3章 生成AIの利用

### 第15条 利用できるサービス

業務で生成AIを使うときは、会社が契約し情報システム課が利用を認めたサービスに限る。個人で契約したサービスに業務情報を入力してはならない。

### 第16条 入力してはならない情報

会社が認めたサービスであっても、次の情報は入力してはならない。

- 取引先から秘密保持契約のもとで受け取った図面・仕様書
- 従業員や顧客の個人情報（氏名と連絡先の組み合わせなど）
- 公表前の決算情報

### 第17条 生成物の確認

生成AIが作成した文章・コードを社外に出すときは、作成者が内容の正しさを確認する責任を負う。
