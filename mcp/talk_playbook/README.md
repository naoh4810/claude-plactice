# 業種別トークMCP（talk-playbook）

業種を伝えると、**よくある悩み・刺さる提案（どのデモを見せるか）・30秒の一言トーク・最初に聞く質問・気をつけること**を返す MCP サーバーです。
交流会の前日に「会いそうな業種」の準備をしたり、名刺を見た直後に一言を考えたりするために作りました。
営業シートで何度も出てきた「士業に会ったら何を話せるか」「SNS 系の人に何を提案すればいいか」に答えるのが目的です。

## ツール

| ツール | 内容 |
|---|---|
| `list_industries` | 手引きがある業種（18種）の一覧 |
| `match_industry` | 名刺の肩書き・事業名などの自由な文から近い業種を探す（例:「まちのわ司法書士事務所」→ 司法書士） |
| `get_playbook` | 業種の手引き。提案ごとに、そのデモが**実演できるか／まだ構想か**を付ける |
| `prep_for_event` | 参加者（事業名）の一覧から、一人ずつの一言・最初の質問・見せるデモと、用意しておくデモの一覧 |
| `log_insight` | 現場で分かったこと（何が刺さった・外した）を業種ごとの現場メモに残す。次に同じ業種を引くと一緒に出る |

プロンプト:

- `event_prep` : 交流会の前日。参加者ごとに1行（業種／最初の一言／最初の質問／見せるデモ）の表を作る
- `after_event` : 交流会の後。会った人の反応から業種ごとの学びを現場メモに残し、フォローの一言を決める

## 手引きがある業種

税理士・会計／司法書士・行政書士／歯科・クリニック／整体・鍼灸・治療院／美容室・サロン／福祉・障害者支援／EC・物販／家庭教師・塾／観光・地域サービス・ふるさと納税／人材・派遣／FP・保険・金融／デザイナー・カメラマン・動画／建設・外壁・リフォーム／物流・ドライバー／占い・相談業／交流会の主催・コミュニティ／Web・SNS・マーケ支援・AI の同業（協業相手）／業種不明のとき

中身は `playbooks.json` にあります。業種ごとの一般的な傾向だけを書いていて、実在の人物・会社・やりとりは入れていません。
現場で分かったことは `log_insight` で現場メモに残し、手引きそのものを直したくなったら `playbooks.json` を編集してください。

## 「実演できる」と「構想」

提案には `mcp/` のデモを紐づけています。

- **実演できる** : A1 営業シート／B1 フォーム→帳票／B2 EC運用／B3 社内検索／B5 SNS一括投稿／B6 短縮リンク
- **構想** : B4 問題バンク／B7 LINE予約・配信／B8 士業の期限・書類／B9 写真→見積／B10 交流会マッチング／B11 家計見直し

構想のデモは「作れます」とは言えても「お見せできます」とは言えないので、手引きでは区別して返し、`demo_to_show`（その場で見せるデモ）には実演できるものだけを選びます。
デモを新しく作ったら `server.py` の `DEMOS` を `ready` にしてください（テストが、実演できるデモの実装が `mcp/` にあるかを確かめます）。

## 営業シートMCPとの組み合わせ

両方を登録しておくと、次のような頼み方ができます。

- 「営業シートで名刺交換だけで止まっている人に、業種ごとのフォローの一言を考えて」→ `stalled_contacts` ＋ `get_playbook`
- 「今月会った税理士さんとの話で分かったことを現場メモに残して」→ `search_contacts` ＋ `log_insight`

## 動かし方

```bash
pip install -r mcp/talk_playbook/requirements.txt

# 現場メモをメモリ上だけで試す
claude mcp add talk-playbook -- python mcp/talk_playbook/server.py

# 現場メモをファイルに残す（リポジトリの外に置く）
claude mcp add talk-playbook -e TALK_NOTES_PATH=/path/to/talk_notes.json -- python mcp/talk_playbook/server.py
```

現場メモには個人名・会社名・連絡先を書かないでください（ツールの説明でも Claude にそう指示しています）。

## テスト

```bash
pip install pytest
python -m pytest mcp/talk_playbook/test_server.py
```

`mcp/` 配下の各サーバーはモジュール名（`server` など）が同じなので、テストはサーバーごとに分けて実行してください。

## 制限

- 業種の判定はキーワードの一致。当てはまらないときは「業種不明のとき」の手引きを返すので、相手の事業を一言で聞いてから引き直す
- 手引きの内容は一般的な傾向。相手ごとの事情は、最初の質問で確かめる前提
